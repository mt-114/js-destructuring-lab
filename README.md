# JavaScript ES6 Destructuring Lab

This project is part of a JavaScript ES6 Lab focused on understanding and practicing data destructuring in JavaScript.

---

## 📌 Project Overview

The project demonstrates how to use:

- Array destructuring
- Object destructuring
- Nested destructuring
- Default values
- Variable renaming
- Function parameter destructuring

The lab helps improve code readability and efficiency using modern ES6 syntax.
